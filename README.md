# HIGHRES Music Player

**Local Music** is a standalone Android player for your offline music library. Browse by song, album, artist, or folder, organize playlists, and tune playback with graphic or parametric EQ.

**[Download Local Music 0.14.2 Beta 1](https://github.com/HERACLES02/HIGHRES-MUSIC-PLAYER/releases/tag/v0.14.2-beta1)** · Android 11 or later

The release page includes the signed APK, its SHA-256 checksum, and backup and restore steps for anyone switching from a preview signed with a different key.

## Report a beta bug

Open [one GitHub issue per bug](https://github.com/HERACLES02/HIGHRES-MUSIC-PLAYER/issues/new). Include:

- Local Music version
- Phone model and Android version
- Steps to reproduce
- Expected behavior and actual behavior

For a playback problem, go to **Settings → Playback & support → Save playback report**. Review the report for song titles before sharing it.
